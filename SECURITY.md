# Security policy

This is a student project and is not maintained as a production service.

Do not report possible vulnerabilities in a public issue. Instead, contact the repository owner privately through their GitHub profile with a clear description and reproduction steps. Please do not include passwords, API keys, or other credentials in the report.

If you have committed a secret, rotate it with the provider immediately; removing a file from the latest commit does not invalidate a credential exposed in earlier commits.
